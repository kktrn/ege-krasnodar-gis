Матрица типологического районирования результатов ЕГЭ по географии в Краснодарском крае на основе сопряженного анализа динамики среднего балла и изменения контингента участников.

Тип муниципального образования Критерии выделения Характеристика образовательной среды
Тип 1: Устойчивый рост Рост участников (>0) и рост балла (>+5) Высокая эффективность профильного обучения, рост популярности предмета.
Тип 2: Рост популярности при снижении балла Рост участников (>+5) при снижении балла (<-3) Массовый охват экзаменом при снижении селективности отбора.
Тип 3: Сниж. участников при росте балла Сокращение участников (<0) при росте балла (>+5) Углубленная подготовка меньшего числа мотивированных учащихся.
Тип 4: Стабильность показателей Колебания в пределах ±5% Инертная среда с устоявшимися результатами без резких сдвигов.
