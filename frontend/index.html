В данном разделе представлена матрица типологического районирования результатов ЕГЭ по географии в Краснодарском крае на основе сопряженного анализа динамики среднего балла и изменения контингента участников за выбранный период.

Тип муниципального образования Критерии выделения (условия) Характеристика образовательной среды
Тип 1: Устойчивый рост Рост участников (>0) и рост среднего балла (>+5 баллов) Высокая эффективность профильного обучения географии, рост популярности предмета при улучшении качества подготовки.
Тип 2: Рост популярности при снижении балла Рост участников (>+5) при снижении среднего балла (<-3) Массовый охват экзаменом при снижении селективности отбора выпускников, сдающих географию по выбору.
Тип 3: Снижение числа участников при росте балла Сокращение участников (<0) при росте среднего балла (>+5) Переход на углубленную подготовку меньшего числа мотивированных учащихся (высокая результативность элитных групп).
Тип 4: Стабильность показателей Колебания балла и участников в пределах ±5% Инертная образовательная среда с устоявшимися результатами обучения без резких качественных сдвигов.
